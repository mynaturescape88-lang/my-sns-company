# jinchi-review-ledger（工程3 章別素材台帳の成果物レビュー）

人智の外側 長尺パイプラインの **工程3（章別素材台帳）** で、制作の背骨となる台帳をゲートする成果物レビュー。親 `jinchi-longform` の工程3末尾から発動。

## 読むのは3つだけ（混在禁止・token効率）
- ① 本skill内の観点リスト＝工程3の合格ライン
- ② `.company/pm/review-baseline.md`＝全レビュー普遍の項目。権利・合法性は content-compliance 発動で確認する
- ③ `.company/sns_accounts/youtube_ainsight.md`＝人智の外側の戦略・コスト前提の照合先

## フロー（発動＝この順で全実行・fail-closed）
- ① 観点の【最上位＋計画段階】を成果物（章別素材台帳）に1つずつ照合し、pass/failを判定する
- ② `pm/review-baseline.md` の各項目を1つずつ照合する
- ③ fail-closed＝1つでもfailなら提出せず修正して①へ戻る
- ④ 【最上位＋計画段階】が全passのみ次の手順へ進む。【最終段階】の観点は各記載工程で当てる

## 工程3の観点（1つずつ照合）
- [ ] **台帳が、実現可能な制作計画として破綻なく成立していること**

### 計画段階（工程3で当てる）
- [ ] 計画として事実で確定できる列が、事実で埋まっていること
- [ ] 実測が要る列に、後で実測へ更新する仮値が埋まっていること
- [ ] 全カットに、①②③★/(間)の5種のいずれかの区分が割り当てられていること
- [ ] カットが再生順に並んでいること
- [ ] VO列がそのカットで読み上げるナレ逐語全文で、要約になっていないこと
- [ ] VO逐語を再生順に章ごと連結すると各章のナレ全文が復元でき、台帳が音声用テキストの正本として成立していること
- [ ] 台帳が予cr・実cr列やcr収支節などのcr概念を含まないこと
- [ ] 設計尺の配分が誤差0で敷き詰められていること
- [ ] 各カットに最高品質の材料が先決されていること
- [ ] 全素材IDが全編でユニークであること
- [ ] ②テロップ板が保持基準の5型のみで構成されていること
- [ ] 本物で作れるカットをAI生成にしていないこと
- [ ] 全素材の取得元がpipeline.md工程5のリスト内であること
- [ ] ロゴ・企業シンボル・公式シール/紋章を社名テキスト表示に置換していること
- [ ] 台帳がテンプレのA表9列・節A〜K・ファイル名に完全準拠していること
- [ ] 台帳が単一正本 `<topic>-cr-ledger.md` として置かれていること
- [ ] 出所未記録の素材を画素・波形の性質測定で代替判定していないこと
- [ ] §Cの想定尺（実測ナレ）に字数からの予測値を入れていないこと
- [ ] ナレ未生成の章の想定尺が「未確定」と明記されていること
- [ ] §Cに合計行があること
- [ ] 後工程へ回す項目（②③の突合）に「未実施・検証工程・合格ライン」が明記されていること

### 最終段階（実測が埋まってから・後工程で当てる）
- [ ] 想定尺が実測ナレ長（ffprobe実測）であること … 工程4
- [ ] 各カットの要求尺が実素材の実尺と一致していること … 工程5-6
- [ ] 図解の割付がアセンブラの実配分と一致していること … 工程7
- [ ] 本番素材が完成したカットにのみ✅がついていること … 工程5-6＋承認
- [ ] §Kの全列が一次規約で充足し、証跡ファイルが実在すること … 工程5-6
- [ ] 未確定が1件も残っていないこと … 最終ゲート（工程10）

## 原則
- レビューに出す成果物は、既知の改善余地がゼロで自分で直せる弱点が残っていないこと。
- 要件未達は自分で不合格にして作り直すこと。
- passした成果物だけを提示すること。
