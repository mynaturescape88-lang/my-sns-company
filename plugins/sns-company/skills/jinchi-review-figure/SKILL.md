# jinchi-review-figure（工程6 図解・合成の成果物レビュー）

人智の外側 長尺パイプラインの **工程6（図解・合成）** で、0cr内製カットをゲートする成果物レビュー。親 `jinchi-longform` の工程6末尾から発動。

## 読むのは3つだけ（混在禁止・token効率）
- ① 本skill内の観点リスト＝工程6の合格ライン
- ② `.company/pm/review-baseline.md`＝全レビュー普遍の項目。権利・合法性は content-compliance 発動で確認する
- ③ `.company/sns_accounts/youtube_ainsight.md`＝人智の外側の戦略・コスト前提の照合先

## フロー（発動＝この順で全実行・fail-closed）
- ① 本skillの観点を成果物（図解／合成カット）に1つずつ照合し、pass/failを判定する
- ② `pm/review-baseline.md` の各項目を1つずつ照合する
- ③ fail-closed＝1つでもfailなら提出せず修正して①へ戻る
- ④ 全passのみ台帳の該当行を済にし、次の手順へ進める

## 工程6の観点（1つずつ照合）
- [ ] **全図解カットの表示尺を全章で実測し、最低表示尺（15秒）に満たない図とループ反復が0件であること**
  - 最低表示尺に届かない図はプール枯渇時のみ取れる最大で止め、achievedを実測で報告する。
- [ ] **図解が暗背景・金アクセント・指定フォントで統一され、下部が字幕帯として空いていること**
- [ ] **図解が2つ連続せず、間に実写・画像を挟んでいること**
- [ ] **合成のグローが円形Hann窓で縁0・暗めベースに合成されていること**
- [ ] **図解・合成が0crで自作されていること**
- [ ] **画面に絵文字が0件であること**
- [ ] **公式画面が幅フィット・上端表示で識別ヘッダが全幅で読め、社名カードが全体読める状態で静止していること**
- [ ] **読ませる文字がある公式画面が最低表示尺（6秒）を満たしていること**
- [ ] **公式画面・社名カードの文字が字形破損・黒地沈みなく正字で判読できること**
  - 実フレーム抽出で綴りを1文字ずつ正しい文字列と突合し、黒一色フレームでないことを輝度で確認する。
- [ ] **焼き込みテキストが視聴者向け文言のみで、制作向け但し書きが0件であること**
- [ ] **全動画カットで実素材の実尺が台帳の要求尺以上であること**
  - 判定は台帳の記載でなく実ファイルのffprobe実測。不足はスロー再生・ループ反復で埋めず、素材を取り直すか台帳の設計尺を再割付する。未取得が残る間はpassにしない。
- [ ] **使用する全素材が商用利用可能で、台帳§Kが全列充足・未確定0件であること**
  - 母集団はA表の全素材＋音素材＋フォント＋OP/ED構成素材。確認は選定時点に配布元の一次規約で行う。
  - 実フレームを抽出し、台帳の記載でなく実映像にロゴ・企業シンボル・紋章が映っていないことを目視する。
- [ ] **全カットが実フレームで黒画面・要素欠落なく視認でき、合成カットは発光が見えること**
- [ ] **自作画面（図解・テロップ板・合成）が禁止帯を避け、安全枠の内側に余白を持って収まっていること**
  - 禁止帯＝上部透かし帯と下部字幕帯。安全枠はそこへ安全マージンを加えた内側。1pxでもはみ出せば不合格。
  - 収まらない図はレイアウトの土台側で全体を等倍縮小して枠の縦中央へ配置する。透かし・帰属バッジは測定母数から除外する。

## 原則
- レビューに出す成果物は、既知の改善余地がゼロで自分で直せる弱点が残っていないこと。
- 要件未達は自分で不合格にして作り直すこと。
- passした成果物だけを提示すること。
