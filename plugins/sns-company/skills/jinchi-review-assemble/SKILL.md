# jinchi-review-assemble（工程7 4Kアセンブルの成果物レビュー）

人智の外側 長尺パイプラインの **工程7（章ごとの完成）** で、組み上げた章動画をゲートする成果物レビュー。親 `jinchi-longform` の工程7から発動する。

## 読むのは3つだけ（混在禁止・token効率）
- ① 本skill内の観点リスト＝工程7のアセンブルの合格ライン
- ② `.company/pm/review-baseline.md`＝全レビュー普遍の項目。権利・合法性は content-compliance 発動で確認する
- ③ `.company/sns_accounts/youtube_ainsight.md`＝人智の外側の戦略・尺前提の照合先

## フロー（発動＝この順で全実行・fail-closed）
- ① 本skillの観点を成果物に1つずつ照合し、pass/failを判定する
- ② `pm/review-baseline.md` の各項目を1つずつ照合する。権利・合法性は content-compliance 発動でfail-closedとする
- ③ fail-closed＝1つでもfailなら提出せず修正して①へ戻る
- ④ 全passのみ次の手順へ進める

## 工程7アセンブルの観点（1つずつ照合）
- [ ] **各カットが、対応するナレ行の実発話区間にアンカーされて配置されていること**
- [ ] **旧1080p版でなく、現行の正規4Kアセンブラで書き出されていること**
- [ ] **字幕・タイトル・ブランドが、PIL PNGのoverlayで焼き込まれていること**
- [ ] **差し替えた画像が、新パスまたは該当カット削除で反映され、同名上書きになっていないこと**
- [ ] **セクション書き出しが、veryfast相当のプリセットで行われていること**
- [ ] **完成章で、同一素材IDが2回以上使われているカットが0件であること**
- [ ] **素材が要求尺に満たないカットでの、承認外のスロー伸長やループ反復による尺埋めが0件であること**
- [ ] **台帳とskillが約束した機構が、この題材のアセンブラの実コードに存在し呼び出されていること**
- [ ] **完成章を含む本編が、実尺15分以上であること**
- [ ] **全図解カットで、台帳の割付尺とアセンブラの実配分での実表示尺が許容誤差内に一致していること**
- [ ] **図解の実表示尺が下限を割って退行しているカットが、0件であること**
- [ ] **完成章の実フレームに、ロゴ・企業シンボル・公式シール・公式紋章が映っていないこと**
- [ ] **完成物の連結対象に含まれる全ての映像・音・フォントが、台帳§Kに行を持っていること**
- [ ] **台帳§Kに、空欄・不明・要確認のセルが0件であること**
- [ ] **各カットの映像が、対応するナレの発話開始onset以降に表示され、先行カットが0件であること**
- [ ] **完成章の音声のper-channel真ピークが、基準値以下であること**
- [ ] **音声鎖が、実測ピークからゲインを算出して基準値以下へ縮小する実装であること**
- [ ] **元ナレ音源の該当区間の試聴で、TTS合成由来のかすれ・割れが無いこと**

## 原則
- レビューに出す成果物は、既知の改善余地がゼロで自分で直せる弱点が残っていないこと。
- 要件未達は自分で不合格にして作り直すこと。
- passした成果物だけを提示すること。
