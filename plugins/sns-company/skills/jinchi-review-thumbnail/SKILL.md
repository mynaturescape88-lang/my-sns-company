# jinchi-review-thumbnail（工程9 サムネの成果物レビュー）

人智の外側 長尺パイプラインの **工程9（サムネの作成）** で、クリック率を決めるサムネをゲートする成果物レビュー。親 `jinchi-longform` の工程9から発動する。

## 読むのは3つだけ（混在禁止・token効率）
- ① 本skill内の観点リスト＝工程9のサムネの合格ライン
- ② `.company/pm/review-baseline.md`＝全レビュー普遍の項目。権利・合法性は content-compliance 発動で確認する
- ③ `.company/sns_accounts/youtube_ainsight.md`＝人智の外側の戦略・サムネ勝ち筋の照合先

## フロー（発動＝この順で全実行・fail-closed）
- ① 本skillの観点を成果物に1つずつ照合し、pass/failを判定する
- ② `pm/review-baseline.md` の各項目を1つずつ照合する。権利・合法性は content-compliance 発動でfail-closedとする
- ③ fail-closed＝1つでもfailなら提出せず修正して①へ戻る
- ④ 全passのみ次の手順へ進める

## 工程9サムネの観点（1つずつ照合）
- [ ] **サムネ文字が、具体的な答えを書かずにインパクトで引く短い煽りになっていること**
- [ ] **サムネ文字が10字以内であること**
- [ ] **使用色がダーク基調＋1アクセントの2〜3色に収まっていること**
- [ ] **被写体が単一であること**
- [ ] **サムネ文字に絵文字が0件であること**
- [ ] **サムネの煽りが動画の内容と乖離していないこと**
- [ ] **直近3回公開した動画のサムネと構成が同じでないこと**
- [ ] **直近3回公開した動画のサムネと文言が同じでないこと**
- [ ] **サムネを3案作っていること**
- [ ] **3案のうちインパクトが最も強い案が第一候補に選定されていること**

## 原則
- レビューに出す成果物は、既知の改善余地がゼロで自分で直せる弱点が残っていないこと。
- 要件未達は自分で不合格にして作り直すこと。
- passした成果物だけを提示すること。
